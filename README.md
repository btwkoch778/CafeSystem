# Cafe System

A simple cafe management system developed using C# and Windows Forms.

## Features

- Simple and user-friendly interface
- Cafe menu management
- Easy navigation
- Organized menu items
- Desktop-based application

## Technologies

- C#
- .NET
- Windows Forms
- Visual Studio
